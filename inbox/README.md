# Inbox: reports from the owner and from Claude chat

Drop files here (GitHub web: Add file > Create new file, branch `claude/eager-bell-i41n67`). Claude Code reads them on its next `git pull`, acts on them, then moves the useful facts into `PROJECT.md`.

Use one file per report, named `YYYY-MM-DD-topic.md`. Paste either a Claude chat REPORT block or the chat itself.

**Never include:** passwords, 2FA or backup codes, access tokens, the App Secret, or screenshots showing any of them. Account IDs and the App ID are fine.
